# Evidenzregister (Atomic Research)

Kette: Experiment → Fact → Insight → Recommendation, jede Zeile mit stabiler ID.
Stories verweisen über `evidenz:` zurück (z. B. I-3, R-4). Regeln:
Facts enthalten keine Deutung · Ideen sind keine Facts · jeder Insight trägt einen
Sicherheitsgrad. Ein Beobachtungs-Agent darf Facts (append-only, mit Provenienz)
ergänzen — Insights und Recommendations bleiben menschlich.
